# Project Core - Repositorio para IA

### Este repositorio contiene toda la información y códigos para los modelos de IA de Project Core.

### Crear el venv:
### python -m venv venv

### Entrar al venv
### venv\Scripts\activate.bat

### Instalar el requirements.txt:
### pip install -r requirements.txt

### Después de instalar el requirements.txt:
### python -m spacy download es_core_news_sm

### Ejecutar el proyecto:
### uvicorn api_service.main:app --reload --port 8001
